# Konemo
A conlang inspired by Korean and Latin, made to be organic, with a simple script.

.tangan beka,.lenga hangul latenngopo,.tanga .meto jong karen .chor bejomo,,,

Find a description of the language at [Definitions](Definitions/README.md) and read translations of Konemo texts under [Texts](Texts/README.md).
In the root there is also a font and the original document in wich the language was created.
